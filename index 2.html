¿Cómo funciona?

De la foto al archivo Excel en tres pasos, sin conocimientos técnicos.

PASO 01

Sube tu documento

Carga una foto, PDF o escaneo. También puedes tomarla directo con la cámara de tu celular.

PASO 02

La IA reconoce los datos

PASO 03

Descarga tu Excel

Revisa los datos, corrige lo que necesites y descarga tu archivo .xlsx listo para usar.

Seguridad técnica

  • La API key nunca llega al navegadorLa clave del servicio OCR vive únicamente en el servidor, como variable de entorno.
  • Llamadas sensibles vía serverlessToda comunicación con el proveedor OCR ocurre en una función del lado del servidor.
  • El Excel se genera en tu dispositivoEl archivo .xlsx se construye localmente con SheetJS; tus datos no viajan de vuelta a ningún servidor.

Política de datos temporales

  • Eliminación inmediataLas imágenes se procesan en memoria temporal y se borran automáticamente al finalizar (máximo 10 minutos).
  • Cero retenciónNo conservamos documentos de usuario ni los utilizamos para entrenar modelos.
  • Sin registros innecesariosSolo se procesa lo estrictamente necesario para generar tu archivo.
Guía rápida de integración: conectar tu API OCR real

El frontend llama a un endpoint del mismo origen (sin claves expuestas). Configúralo antes de cargar la app:

<script>
  window.__DOCTOEXCEL_CONFIG__ = { ocrEndpoint: '/api/ocr' };
</script>

Ejemplo de función serverless (Node) — la clave vive solo aquí

// api/ocr.js — despliega en Vercel / Netlify / Cloud Functions
export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).json({ ok: false, error: 'Método no permitido' });

  const key = process.env.OCR_API_KEY;   // ← variable de entorno del servidor, nunca en el frontend
  if (!key) return res.status(500).json({ ok: false, error: 'Falta OCR_API_KEY' });

  // 1. Recibir el archivo (multipart/form-data, campo "file")
  // 2. Enviarlo al proveedor OCR (Google Vision, Azure Document Intelligence, AWS Textract…)
  // 3. Responder con el contrato normalizado:
  res.json({
    ok: true,
    table: {
      headers: ['Nombre', 'Cédula', 'Teléfono'],
      rows: [[{ v: 'Juan Pérez', c: 0.98 }, { v: '001-0000000-0', c: 0.61 }, { v: '809-000-0000', c: 0.93 }]]
    }
  });
  // 4. Eliminar el archivo temporal inmediatamente después
}

Contrato de respuesta admitido

// Opción A — tabla ya detectada por la API
{ "ok": true, "table": { "headers": ["..."], "rows": [[ { "v": "valor", "c": 0.95 } ]] } }

// Opción B — palabras con coordenadas (el frontend reconstruye la tabla)
{ "ok": true, "words": [ { "text": "Nombre", "x": 40, "y": 120, "w": 70, "h": 16, "conf": 0.97 } ] }

// Opción C — texto plano (se separa por líneas y columnas)
{ "ok": true, "text": "Nombre\tCédula\nJuan\t001-000" }
